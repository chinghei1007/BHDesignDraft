Typography scale

Edit sizes in px; labels use Tailwind naming.

Container spacing

Choose a container and sides. Individual sides override horizontal, vertical and all-side values; spacing steps are 0.25rem (4px).

Sample list styles

Changes apply to the unordered and ordered sample lists, independently of the sidebar.

These are editable CSS tokens, modeled on Tailwind typography and spacing.

Mix layouts and color

Choose a palette above to apply it across every layout. Soft palettes use light navigation; higher-contrast palettes use darker navigation and stronger accents. Original restores each design’s initial colors.

Palette chips are design tokens; test every text and button pairing before production.
